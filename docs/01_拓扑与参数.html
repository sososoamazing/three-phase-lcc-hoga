01 三相 LCC 拓扑、参数与状态方程

本文只描述本仓库归档的三相 LCC 研究对象。所有数值来自原项目 MATLAB_PRJ/three_phase/simulink/three_phase_LCC.slx 及其 InitFcn、接线审计报告和 model_config.m，没有新增仿真。

1.1 主电路

Vin(50 V) ── Rin(1 mΩ) ── 三相三桥臂逆变（S1–S6，120° 互差）
                              │
              每相：电流传感器 → Ls(4.7 μH) → Cs(135 nF) → Δ 节点
                              │
        Δ 接：三条边各并一只 Cp(27 nF) 与一台单相变压器一次绕组
                              │
        三台理想变压器：一次 Δ，二次 Y，二次中性点 N 浮空（不接地、不接输出负端）
                              │
        六二极管整流：D1/D3/D5 上半桥，D2/D4/D6 下半桥
                              │
        Co = 6.25 μF × 2 串联（中点悬空、无均压电阻）→ 等效 3.125 μF
                              │
                          Vo（0 → 800 V，纯电容充电，无输出负载电阻）

关键点：

  • 这是三个半桥（三条桥臂），不是三个独立全桥。
  • Cp 接在 Δ 的三条边上，与三台变压器一次绕组逐边并联；不是每相独立并联，也不在二次侧。
  • 二次 Y 的中性点浮空；六管整流桥共用，不能拆成三个单相整流桥。
  • 输出侧没有负载电阻；Resistor=0.001 Ω 是输入源串联电阻 Rin，不是负载。
  • 稳态比较时把 Co 换成两个 Vo/2 理想电压源，得到“冻结输出电压”的周期稳态；这不等于真实 3.125 μF 充电瞬态。

1.3 坐标与六维差模状态

取三相零和空间的正交基 U、Δ 关联矩阵 B：

B = [ 1  0 -1
     -1  1  0
      0 -1  1 ]

U = [ 1/√2   1/√6
     -1/√2   1/√6
      0     -2/√6 ]

C = U^T B U

定义：

  • i = U q：逆变器流向三条馈线的电流；
  • v_s = U s + b·1：串联电容沿馈线的压降，公共偏置 b 守恒，取 b=0；
  • e = U r：二次侧相对浮空中性点的电压；
  • j = U w：二次侧流向整流桥的电流；
  • 原边绕组电流为 n j；
  • 支路 KCL：i = B (n j + Cp · du/dt)，其中 u = B^T v_x 是 Δ 边电压。

六个独立差模状态：

x = [ qα, qβ, sα, sβ, rα, rβ ]^T

公共方程：

Ls * dq/dt = Vin * p - Rin * p p^T q - s - C r / (3n)
Cs * ds/dt = q
(Cp/n^2) * dr/dt = C^T q / (3n) - w
p = U^T d

其中 d 为三个上管门控。p p^T 包含跨相耦合，不能删；C 矩阵是 Δ/Y 连接带来的，也不能删。

周期平均能量恒等式（独立物理核验）：

W = Ls‖q‖²/2 + Cs‖s‖²/2 + Cp‖r‖²/(2n²)
Vin * mean(i_dc) = (Vo + 2Vf) * Io + Rin * mean(i_dc²)
i_dc = d^T i

1.4 六管整流的精确约束

令 Vd = Vo + 2Vf，A 的六行是 U_a - U_b（a ≠ b，对应六种上/下管组合）。可行域是六边形：

K = { r : A r ≤ Vd * 1 }
w ∈ N_K(r)
io = Σ_a max(j_a, 0) = (1/2) Σ_a |j_a|

最后一条等式只有在零和电流与二极管可行性成立时才成立；不能把任意候选的 Σ|j|/2 直接当成合法整流电流。

w ∈ N_K(r) 同时表达：

  1. 导通的二极管对把对应线电压钳在 Vd；
  2. 关断的二极管反压非负；
  3. 导通二极管电流非负；
  4. 互补条件（电压间隙 × 电流 = 0）。

允许两管、三管和全截止区间。全截止时二次侧绝对电位不唯一，存在 DC 代表解族；固定一个代表解只说明“存在周期解”，不证明实际充电可达。

1.5 CCM 的定义

本项目的 CCM 定义是：

整流桥不存在有限时长的“全截止”区间。

不是“谐振电感电流不穿过零”。因此：

  • 100 V 附近存在约 43.87% 的三管重叠区间；
  • 400 V、700 V 为连续两管主导；
  • 800 V/280 kHz 含约 7.4% 全截止区间；
  • 800 V/240 kHz、260 kHz 为全截止周期代表解（Io = 0）。

不能把“所有工作点都是 CCM”当成前提。

1.7 常见错误清单

  1. 把 Cp 当成每相 27 nF 并联 → 实际是 Δ 每边 27 nF，平衡星等效 81 nF。
  2. 把 Co 当成 12.5 μF 并联 → 实际是两只 6.25 μF 串联，等效 3.125 μF。
  3. 把 Resistor=0.001 Ω 当负载 → 它是输入源串联电阻，输出没有负载电阻。
  4. 把三个单相结果相加或乘 3 → 三相共用六管桥，Δ/Y 耦合不能这样拆。
  5. 把 n=4 再乘 √3 → 单绕组变比就是 4；相数因子已在整流系数中体现。
  6. 把单相 LCC 的 v_Cp = ±Vo/n 平台判据套过来 → 本拓扑是三相分段钳位，约束是 Vo = n(max p_j − min p_j) 一类联合约束。
  7. 把“文件名 ideal”当成“满足全部比较条件” → ideal_three_phase_LCC.slx 的二极管 Vf=eps，与 0.6 V 基准不同。
