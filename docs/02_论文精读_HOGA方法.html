02 论文精读：High-Order Generalized Averaging（TPEL 2024）

论文：Hongchang Li, Kangping Wang, Jingyang Fang, Wenjie Chen, Xu Yang, “High-Order Generalized Averaging Method for Power Electronics Modeling From DC to Above Half the Switching Frequency,” IEEE Transactions on Power Electronics, vol. 40, no. 1, pp. 176–194, Jan. 2025. DOI: 10.1109/TPEL.2024.3450712。 本仓库 paper/ 保存了论文 PDF（作者接受版，页脚标注 CC BY-NC-ND 4.0）。本文是阅读笔记，不是论文译文；公式和页码以原 PDF 为准。

2.1 论文要解决的问题

传统状态空间平均法只在“关注频率远低于开关频率一半”时有效，因为它把开关周期内的纹波平均掉了。采样数据模型、描述函数、EDF、广义平均等可以做到更高频，但通常：

  • 需要逐段时域波形推导；
  • 只保留 DC + 基波时，有效范围仍被限制在 fs/2 以下；
  • 多频/HSS 模型虽然能到 fs/2 以上，但常局限于 Buck 类 CCM 电路，且要把闭环控制一起纳入。

论文的目标是：用移动 Fourier 系数（moving Fourier coefficients）建立一套统一的高阶广义平均（HOGA）框架，把有效频带从 DC 扩展到 fs/2 以上，并把电路与调制器/控制器分开建模。

2.2 核心数学工具

论文第 II 节给出移动 Fourier 系数的性质。对周期为 T 的信号 x(t)：

<x>_n(τ) = (1/T) ∫_{τ-T/2}^{τ+T/2} x(t) e^{-jnωt} dt,   ω = 2π/T

关键性质（论文式 (4)–(23)）：

性质 表达式 在建模中的作用
线性 <a x + b y>_n = a<x>_n + b<y>_n 状态方程可以逐项变换
乘法 <x y>_n = Σ_l <x>_l <y>_{n-l} 开关信号与状态相乘变成 Toeplitz 卷积
时导 d/dt <x>_n = <dx/dt>_n + jnω<x>_n 把时变系统变成 LTP 形式
偏导 ∂<x>_n/∂<y>_m = <∂x/∂y>_{n-m} 小信号 Jacobian 的 Toeplitz 结构
Laplace L{<x>_n}(s) = sinc(...) · X(s+jnω) 解释“信号—边带”耦合

其中最重要的是乘法 → 离散卷积 → Toeplitz 矩阵。它使得：

  • 大信号模型可以写成 K d<x>/dt = f(<x>, <s>, <u>) 的形式；
  • 小信号模型在稳态工作点线性化后是 LTI 的，但状态变量是“各阶移动 Fourier 系数”，因此能描述边带耦合；
  • 关注频率可以超过 fs/2，因为模型里保留了 ±1, ±2, ..., ±H 阶。

2.3 电路建模流程（论文第 III 节）

论文把理想电力电子电路写成以开关信号为参数的分段线性状态空间：

K dx/dt = A(s) x + B(s) u
y = C(s) x + D(s) u

然后：

  1. 对状态、输入、开关信号取移动 Fourier 系数；
  2. 用乘法性质把 A(s)x 变成 Toeplitz 卷积；
  3. 得到大信号 HOGA 模型：
K d<x>/dt = A(<s>) <x> + B(<s>) <u> - jNω K <x>
  1. 稳态时 d<x>/dt = 0，得到线性平衡方程：
0 = A(<s>) <x> + B(<s>) <u> - jNω K <x>
  1. 在稳态点线性化，得到小信号 LTP → LTI 模型：
K d<x̃>/dt = (A - jNωK) <x̃> + ...
  1. 由小信号模型计算传递函数矩阵，解释信号与边带的耦合。

论文强调：电路和调制器/控制器可以分开建模，再线性组合。这是它相对于“把闭环一起塞进 HSS”的一个工程优势。

2.4 开关信号建模（论文第 IV 节）

这是论文对本项目最直接相关的部分之一。论文不要求先写出开关波形的时域表达式，而是用上升/下降时刻来描述开关信号：

  • 开关信号 s(t) 在 [τ-T/2, τ+T/2) 内有唯一的上升时刻 t_r(τ) 和下降时刻 t_f(τ)；
  • <s>_0 = mod[(t_f - t_r)/T, 1]；
  • <s>_n = (1/(j n π)) e^{jn∠<s>_1} sin(nπ<s>_0)（n ≠ 0）；
  • 对 t_r、t_f 的偏导有解析式。

然后分三类讨论开关时刻如何由其他信号决定：

  1. 过零点：x(t_0)=0，得到 ∂t_0/∂<x>_m 的解析式（论文式 (44)–(47)）。这适用于 DCM 二极管关断（电流过零）。
  2. 函数的过零点：f(x,t)=0，用链式法则得到 ∂t_0/∂<x>（论文式 (49)–(53)）。这适用于 PSM/PFM 的载波过零。
  3. PWM/PSM/PFM 的具体模型：PWM 用占空比与载波之差过零；PSM 用相位调制；PFM 把频率写成 ω_s(t)=ω+α'(t)，再转成 PSM 处理（论文式 (54)–(55)）。

论文给出了 PWM 三种载波（三角、锯齿、反锯齿）的显式模型（Table 2），以及 CCM/DCM 下二极管互补/状态相关开关的模型。

2.5 三个实例与验证

论文第 V–VII 节分别建模：

实例 控制 验证内容 关键结果
Boost PWM CCM/DCM 稳态波形、占空比—输出电压传递函数 在接近/超过 fs/2 时比传统平均模型准
Buck V² 恒定导通时间 CCM/DCM、控制电压—输出电压传递函数 首次给出该控制的 DCM HOGA 模型；高频段优于描述函数模型
LLC PFM 低于/高于谐振频率的稳态波形、频率—输出电压传递函数 在 80 kHz 与 120 kHz、调制到 150 kHz 时仍与实验吻合

论文实验里用了 −49…+49 阶移动 Fourier 系数（即 H=49），说明“几十阶”在实际中已经能得到很好的波形。论文也明确指出：截断会扭曲稳态波形并给传递函数带来误差；截断阶数与误差的定量关系是未来工作。

2.6 论文的假设与边界

论文结论部分列出三条假设：

  1. 信号有界变差（物理可实现信号满足）；
  2. 电路由理想器件组成，可写成分段线性状态空间；
  3. 变换器存在与稳态工作点对应的周期解。

此外还有几条对使用者很重要的边界：

  • 模型理论上是无限维的，实际计算必须截断到有限阶；
  • 论文的验证是 Boost/Buck/LLC 三个单相例子，没有三相 Δ/Y LCC，也没有共用六管桥；
  • 论文的小信号模型是“在稳态周期解附近”的 LTP 线性化，不替代大信号充电轨迹；
  • 论文没有给出“截断阶数—误差”的严格上界，也没有证明周期解全局唯一或稳定；
  • 论文的 PFM 模型针对频率调制，不是“每个工作点固定频率”的冻结稳态求解。

2.7 与本项目三相 LCC HOGA 的关系

论文内容 本项目对应 关系
移动 Fourier 系数、+jnω、Toeplitz 卷积 lcc3v2Hoga.m 的复 Fourier 系数、Kf、Pz/Qz 卷积 直接采用其数学语言
分段线性状态空间 + 开关信号 六维差模状态 x=[q,s,r]，门控 d，六管整流 本项目把论文的“电路”扩展为三相 Δ/Y + 共用六管桥
开关时刻/过零模型 二极管事件、门控边沿 0,1/6,...,5/6、事件残差 本项目没有用论文的小信号过零偏导，而是把事件时刻作为未知量，直接闭周期解
稳态线性平衡方程 lsqnonlin 解事件残差 + 谱方程 本项目是事件增强的 Fourier-Galerkin 周期稳态，不是论文的线性平衡方程
小信号 LTP → LTI 未实现 本项目目前只做冻结周期稳态，没有做移动窗口小信号/变频动态
H=49 实验 AOC 验证用 H49；主比较用 H31 阶数选择受精度/成本权衡，不是论文的固定推荐
单相 Boost/Buck/LLC 三相 LCC 论文没有本拓扑的现成公式；本项目的三相方程、整流约束、事件闭合均为独立推导/实现

一句话总结：

论文提供了“用多阶移动 Fourier 系数突破 fs/2”的一般理论、开关信号建模方法和 LTP 小信号框架；本项目把其中的多阶 Fourier 表示用于三相 Δ/Y LCC 的冻结周期稳态，并用事件增强 + 精确分段整流约束替换了论文的线性平衡/小信号部分。

2.8 读论文时最容易误解的地方

  1. “HOGA 能到 fs/2 以上”不等于“任意阶数都准”。论文自己说截断误差没有定量上界；本项目也观察到升阶不保证每个指标单调变好。
  2. 论文的“state-dependent switching”是给小信号偏导用的。本项目把二极管事件作为精确约束直接求解，二者不是同一个数值问题。
  3. 论文的 LLC 是单相 PFM，不能把它的 LLC 公式直接套到三相 LCC；三相的 Δ/Y、共用六管桥、浮动中性点都要重新推导。
  4. 论文的 H=49 是实验选择，不是“必须 49 阶”；本项目在 20 点比较里用 H31，在 AOC 验证里用 H49，二者证据等级不同。
  5. 论文的传递函数是边带耦合的 LTI 表示，不是“把开关纹波当噪声”的粗略平均。
