怎么读

  1. 先读 docs/02_论文精读_HOGA方法.md，建立“移动 Fourier 系数 → 卷积/Toeplitz → 稳态/小信号 → 开关信号模型”的框架。
  2. 再读 PDF 的第 II–IV 节（性质、电路模型、开关信号模型）。
  3. 第 V–VII 节是 Boost/Buck/LLC 三个实例；重点看 LLC 的 PFM 处理，但注意它是单相。
  4. 第 VIII 节结论列出三条假设和“截断误差无定量上界”的局限。

与项目的关系

论文提供一般理论；本项目的三相 Δ/Y LCC、共用六管桥、事件增强 HOGA 是独立推导/实现。不要把论文的 Boost/Buck/LLC 公式直接套到本拓扑。详见 docs/02 的 2.7 节映射表。
